# IEEE journal and SCIE destination contract

Read when selecting a venue, initializing a manuscript template or verifying its final format. The user's default paper destination is an IEEE journal; verify SCIE indexing for the actual selected title. This reference supplies obligations, not a current endorsement, confirmed indexing, installed template, working compiler or guarantee of acceptance.

## Establish the venue record

Record journal/title/identifier, article type and scope, current official author instructions, template source/version/retrieval date, verified indexing evidence/date, limits, review/anonymization policy, figure/supplement/declaration requirements, AI-use/disclosure rules and applicable charges. Check unstable facts near use through official journal sources and current Clarivate evidence where accessible. IEEE affiliation, an impact factor or an old list cannot establish current SCIE coverage. SCIE is an index designation, not one template. Use the [Clarivate index description](https://webofscience.help.clarivate.com/Content/wos-core-collection/wos-core-collection.htm) for the distinction; absent accessible title-level verification stays unverified while independent writing continues.

Use the [official IEEE Template Selector](https://journals.ieeeauthorcenter.ieee.org/create-your-ieee-journal-article/authoring-tools-and-templates/tools-for-ieee-authors/ieee-article-templates/) for the selected journal/article type. Retain official class/style/bibliography files and provenance. Apply actual column layout, headings, equations/algorithms, figure/table placement, citation style, author or anonymous-review form and limits. Do not blindly import Orchestra conference defaults, generic double columns or ARS APA defaults. If no journal is selected, an appropriate official generic IEEE journal template can yield a clearly provisional draft; it is not a journal-specific verified submission.

Prefer editable LaTeX with actually compiled/inspected PDF for mathematical work. Other requested editable formats need verified faithful conversion. A separate contracted thesis retains its institution's actual template unless user instructions say otherwise. See [writing artifacts](writing-artifacts.md).

## Scientific content and author metadata

Use the article's evidence type to organize the bounded question/contributions, relevant literature/gap, formulation, method, justified equations/pseudocode, reproducible implementation/resources, design/baselines/metrics/statistics, results/ablations, interpretation/limitations, conclusion, verified references and useful reproduction supplements. Follow [IEEE article-structure guidance](https://journals.ieeeauthorcenter.ieee.org/create-your-ieee-journal-article/create-the-text-of-your-article/structure-your-article/) alongside journal-specific instructions. Reviews/theory/negative studies adapt structure rather than invent empirical sections. The abstract summarizes actual findings and caveats; concise formatting must preserve the scientific argument.

Use only actual author-provided names, affiliations, contributions, funding, authorship, originality/overlap, data/code availability and required declarations. Template examples cannot create received/accepted dates, manuscript IDs, DOI, editorial notices or approval credentials. Keep missing essential inputs visibly pending. Current venue AI-use/disclosure obligations and mandatory human verification remain separate from the agent's evidence checks. No source formatting or high score fabricates an author decision.

## Build, inspect and gate

Discover an actual supported project compiler and resolve dependencies within authority; do not claim TeX exists because an upstream skill mentions it. The desktop standalone compiler supports its documented standalone-file contract and must not be assumed to build arbitrary multi-file IEEE projects. Preserve all source artifacts if project compilation is unavailable and report exact missing capability. A generic PDF generator may make a preview but cannot certify compilation/compliance of an unbuilt official LaTeX project.

When available, build the real project, resolve bibliography/cross-references, retain exact commands/runtime/logs, output hashes and unresolved warnings, and inspect every page plus fonts/equations/figures/tables. Confirm selected journal template/citations/layout/limits, readable actual-size figures and substantive manuscript consistency. Source-only checks, opening the editor and metadata validation do not replace successful build and visual inspection. Use relevant PDF/documents tools for inspection under their actual runtime contracts.

The final independent scientific/citation review, native verifier/critic, selected ARS integrity/re-review/author carriers and journal-format check all bind the actual current artifact. A later build/bibliography/diagram/citation edit reopens affected gates without inventing a blanket need to rerun unchanged experiments. Required reproduction and paper/thesis inventory checks follow [completion](reproduction-completion.md).

Deliver only achieved statuses: evidence-audited draft, provisional IEEE journal-style draft, journal-format-checked draft, author-review-pending, or author-approved submission package. Unknown indexing, required author inputs, compiler absence or unresolved formatting remain visible. An author-review-pending draft can be delivered as such; it cannot be called author-approved. Journal acceptance remains an external editorial outcome. Export never implies submission, public publication or contact with editors/reviewers.
